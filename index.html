Call-Centre Speech Analytics

Yash Chaudhary, 2026 · GitHub · LinkedIn

A live exam-helpdesk portal paid Gemini to transcribe and categorise every call. This is the self-hosted engine that replaced it: Hindi and Hinglish audio in, the portal's ticket fields out, on one GPU running open models.

Method

Gemini's past answers were the only labels available, so every stage is trained to agree with Gemini and measured on calls it never saw.

recording, 8 kHz
  → Silero VAD              speech segments of at most 25 s
  → Whisper-turbo           fine-tuned on 4,183 helpdesk calls (111 h)
  → speaker roles           words + voice features + Viterbi → agent / candidate
  → category classifier     TF-IDF SVM + bge-m3 embeddings + nearest past calls,
                            combined by a boosted re-ranker; 5 categories, 196 sub-categories
  → Qwen3-4B (llama.cpp)    agent rubric, resolution, insight, summary
  → portal fields           JSON over HTTP, or the portal's Excel export layout

Cost and deployment

On one T4 GPU (AWS g4dn.xlarge) the full pipeline handles about 6 calls a minute, roughly ₹0.13 per call. The server sleeps when idle; the portal wakes it through AWS Lambda once calls queue up. Calls below a confidence threshold go to a person with the model's next two guesses, and one setting switches the portal back to Gemini.

Decisions

Self-host instead of paying per call.
A fine-tuned open model on one GPU that runs only while calls are waiting, with Gemini kept as a one-setting fallback.
A trained classifier for categories, not an LLM prompt.
Stacking a text classifier, embeddings and similar past calls raised sub-category agreement from 35.3% to 53.2% on the same held-out calls.
A small LLM only where free text is needed.
Qwen3-4B writes the summary, insight and agent rubric; everything that can be measured as a label is handled by a cheaper, testable model.
Route doubt to a person.
With human agreement near 61%, a confident wrong answer costs more than a short review, so low-confidence calls go to an agent with alternatives attached.
